# hello-amiga

This project contains Amiga code examples.


## Prerequisites

* [vbcc](http://sun.hasenbraten.de/vbcc/index.php)
* [ratr0-utils](https://weiju.github.io/ratr0-utils/index.html)
* [fs-uae](https://fs-uae.net/)

Ensure the `NDK_INC` environment variable points to NDK 1.3:

```sh
export NDK_INC="/opt/amiga/NDK_1.3/Includes1.3/include.h"
```

## Examples

To run an example:

```sh
make example1
```
